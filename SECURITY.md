# Sécurité et signalements privés

Pour signaler une faille, une fuite de donnée personnelle (par exemple une adresse publiée par erreur) ou un
comportement contraire au code de conduite, utilisez le **signalement privé** de GitHub : onglet *Security*,
bouton *Report a vulnerability*. Ne publiez pas ces informations dans une issue publique.

Nous accusons réception sous 7 jours. Le projet est bénévole : aucun délai de correction n'est garanti.

Versions suivies : la dernière version publiée uniquement.
