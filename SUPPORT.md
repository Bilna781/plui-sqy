# Obtenir de l'aide

- **Question d'utilisation** : onglet *Discussions*, catégorie Q&A.
- **Règle mal lue ou fausse** : issue « Règle fausse », avec le code de zone, l'article et la page du règlement.
- **API ou script en erreur** : issue « API cassée », avec le message d'erreur.

Ne publiez jamais votre adresse : un code de zone et un numéro d'article suffisent.
Pour toute question sur votre projet réel, adressez-vous au service urbanisme de votre commune : ce projet est
non officiel et ne remplace ni un certificat d'urbanisme ni l'avis du service instructeur.
